# 左偏树

</br>

<p>左偏树本质上是一个堆，首先支持堆的操作（插入(O(logn))，求最小值(O(1))，删除最小值(O(logn))）。以及体现左偏树特性的合并两颗左偏树，复杂度为 O(logn)，效率比较高</p>

<p>需要维护值 dist：节点到距离其最近的空节点的距离（叶节点的 dist 为 1）</p>

<p>左偏树保证，对于任意节点，左儿子的 dist 大于等于右儿子的 dist</p>

<p>右子树的高度为 O(logn)，所以保证根节点的距离为 O(logn)</p>

<p>证明：可用数学归纳法证明 f(k) >= 2^k-1 ：f(k) 表示距离为 k 的点<b>至少</b>包含几个点。2^k - 1 <= n，所以 k <= logn + 1。所以左偏树的操作最坏是 logn</p>

</br>

## 核心操作--合并操作

</br>

<p>合并树 a 和 b，并返回合并后的根节点</p>

<p>不妨设 a <= b，合并后的根节点应该是 a 点。a 的左子树就不需要变化了，然后将 a 的右子树和 b 去合并，<b>这是一个递归的过程</b>。合并完之后需要判断：左子树的距离是否大于右子树的距离，若大于则交换</p>

<p>a 的距离开始是 dista，b 为 distb，下一次会合并 a 的右子树和 b，变为 dista-1 和 b，每次递归都会有 a 和 b 其一的 dist 减一，当 a 或者 b 减到 0 的时候，就是将一棵树将空节点合并，所以最多递归 dista + distb 次</p>

Node* merge(Node* a, Node* b) {
    if (!a) return b;
    if (!b) return a;

    if (a->val > b->val)
        swap(a, b);

    a->r = merge(a->r, b);

    if (!a->l || a->l->dist < a->r->dist)
        swap(a->l, a->r);

    a->dist = (a->r ? a->r->dist : 0) + 1;

    return a;
}

<p>用 merge 操作完成其他操作：</p>

- 插入一个数：插入一个节点，用该节点建立只包含一个节点的左偏树，然后合并

- 删除最小值：将根拿掉，然后将根的左右子树合并，得到新的根
