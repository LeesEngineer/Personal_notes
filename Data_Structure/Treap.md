# Treap

</br>

<p>Treap 可以看作二叉搜索树和堆的结合</p>

<p>说实话，写平衡树的地方一般都写 splay 了。</p>

<p>平衡树一般没有相同权值，如果遇到该情况，可以维护一个计数器 count</p>

<p>搜索树应该满足哪些操作</p>

- 插入 / 删除

- 找前驱 / 后继

- 找最大 / 最小

- 求某个值的排名

- 求排名是 k 的数是哪个

- 比某个数小的最大值，比某个数大的最小值

<p>找一个节点的前驱和后继就是找他在中序遍历时的前一个节点和后一个节点</p>

<p>Treap 的思想是让 BST 尽量随机，达到 logn。</p>

```
struct Node
{
    int l, r;
    int key, val;
} tr[N];
```

<p>key 是搜索树用来排序的关键字，val 是堆的值。如果所有的 key 和 val 互不相同，那么 Treap 的结构是唯一确定的（最小的 val 一定是根，第二小和第三小的 val，根据 k 的值决定谁是右儿子和左儿子，以此类推）</p>

<p>val 是一个随机值</p>
