# 质数

质数的判定：

1. 试除法 O(n)

优化的话有一个很重要的性质：如果 d 能整除 n 的话（d | n），那么 n/d | n 也成立。所以可以把 d 遍历到 n 变为 d 遍历到 d/n (不推荐执行 sqrt(n)，因为每一次循环都会执行 sqrt。也不推荐 i * i <= n，因为当 n 接近 int 的最大的时候，i * i 前面还是小于 n 的，i+1 直接溢出了)。

2. 分解质因数

埃氏筛法

```
#include <iostream>

using namespace std;

const int N = 1e6 + 10;

int primes[N], cnt;
bool st[N];

void get_primes(int n)
{
    for(int i = 2; i <= n; i ++)
        if(!st[i])
        {
            primes[cnt ++] = n;
            for(int j = i + i; j <= n; j += i) st[j] = true;
        }
}

int main()
{
    int n;
    cin >> n;
    
    get_primes(n);
    
    cout << cnt << endl;
    
    return 0;
}
```

只需要筛选质数的倍数就可以了，<b>争取把每一个合数用他的质因子筛选出来。</b>时间复杂度为 O(nloglogn)

线性筛法

```
#include <iostream>

using namespace std;

const int N = 1e6 + 10;

int primes[N], cnt;
bool st[N];

void get_primes(int n)
{
    for(int i = 2; i <= n; i ++)
    {
        if(!st[i]) primes[cnt ++] = i;
        for(int j = 0; primes[j] <= n / i; j ++)
        {
            st[primes[j] * i] = true;
            if(i % primes[j] == 0) break;
        }
    }
}

int main()
{
    int n;
    cin >> n;
    
    get_primes(n);
    
    cout << cnt << endl;
    
    return 0;
}
```

每个合数只会被筛选一次，故时间复杂度为 O(N)

<b>固定一个整数 i，枚举质数，将它们相乘构造合数，并通过 break 避免重复标记。对于当前的 i，内层循环只会枚举到 i 的最小质因子，之后就会 break。</b>
